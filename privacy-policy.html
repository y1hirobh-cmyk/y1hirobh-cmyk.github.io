プライバシーポリシー

制定日：2026年11月22日

対象

このポリシーは、個人用ツール「Muse YouTube Analytics」（以下「本ツール」）における Google ユーザーデータの取り扱いを定めるものです。本ツールの利用者は開発者本人1名のみで、一般公開サービスではありません。

取得するデータ

本ツールは、YouTube Analytics API と YouTube Data API v3 を通じて、開発者本人が所有・管理する YouTube チャンネルの統計データ（再生回数、総視聴時間、登録者の増減、平均視聴割合など）を読み取り専用で取得します。動画の変更・削除・アップロードは行いません。

利用目的

取得したデータは、開発者本人のチャンネル運用の分析と振り返りのためだけに使います。

保存と共有

取得したデータは開発者のローカル環境でのみ処理・保存します。第三者への提供、販売、公開はしません。本ツールが Google API から受け取った情報の使用は、Google API Services User Data Policy（Limited Use の要件を含む）に準拠します。

アクセスの取り消し

本ツールへのアクセス許可は、Google アカウントのセキュリティ設定（サードパーティ アクセスの管理）からいつでも取り消すことができます。
